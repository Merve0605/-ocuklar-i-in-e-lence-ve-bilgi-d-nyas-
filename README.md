# çocuklar-için-eğlence-ve-bilgi-dünyası

Çocuklar için tasarlanmış sesli, etkileşimli ve eğitici web uygulaması. Okuma bilmeyen çocuklar dahil tüm çocukların kendi başlarına keşfederek öğrenmesini sağlar.

🚀 Özellikler & İçerik

🔊 Sesli Destek: Tıklanan tüm kelimeleri ve yanıtları Türkçe seslendirir.

📱 Mobil Uyumlu: Tüm cihazlarda (telefon, tablet, bilgisayar) rahatça çalışır.

📚 Eğitici Kartlar: Sayılar (1-10), Hayvanlar, Yabancı Diller (6 dilde "Merhaba"), Dünya Kültürleri, Sporlar ve Taşıtlar.

🎮 Mini Oyunlar: Renk eşleştirme, sayı sıralama zeka oyunu ve etkileşimli bilmeceler.
